# Dental Booking Website

A dental booking website built with HTML, CSS, C#, ASP.NET Core, and SQL Server.

## Features

- Doctor selection
- Service selection
- Appointment booking
- Database integration
- Responsive web design

## Technologies

- HTML
- CSS
- C#
- ASP.NET Core
- SQL Server
